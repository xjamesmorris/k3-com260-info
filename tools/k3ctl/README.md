# k3ctl has moved

k3ctl, the USB header-button controller for the K3-CoM260 on the Firefly
carrier, moved to
[k3-tools](https://github.com/xjamesmorris/k3-tools/blob/main/k3ctl/README.md)
on 2026-11-19, with its history. Its firmware, client, udev rule, tests and
[recorded hardware results](https://github.com/xjamesmorris/k3-tools/blob/main/k3ctl/README.md#recorded-hardware-results)
are maintained there.

The last version in this repository is at commit
[`7e8c58f`](https://github.com/xjamesmorris/k3-com260-info/tree/7e8c58f1308b822c857204ba600238e9699e3947/tools/k3ctl).
This directory keeps its `.gitignore` so that build and cache files in
existing checkouts stay ignored.
